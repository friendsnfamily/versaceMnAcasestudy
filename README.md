# versaceM-Acasestudy

**Versace Acquisition: DCF Valuation & Deal Analysis**

This project examines Prada Group's acquisition of Versace through an independent standalone valuation of the business, using historical financial disclosures from Capri Holdings, Versace's former parent company.

The objective is to estimate Versace's intrinsic value independently of the transaction and assess the operating performance implied by Prada's agreed acquisition price. Rather than simply comparing the purchase price against a standalone valuation, the analysis seeks to understand the assumptions required to bridge the difference.

**Key Findings**

  Estimated standalone enterprise value of approximately US$1.05bn, compared with the reported US$1.375bn acquisition price.
  
  Forecast EBIT margin recovery from -6.6% in FY2025 to 11% by FY2030.
  
  Reverse valuation examined the earnings expectations embedded in the acquisition price.

**Limitations**

Certain capex and working-capital figures rely on estimates. The model does not quantify Prada-specific synergies or reproduce its internal valuation.

This project is for educational and illustrative purposes only and does not constitute financial or investment advice.
